## 覆盖的基本行为

| 范围 | 检查 |
| --- | --- |
| 任务与修订 | 定向失效、新约束保守复核、相同值不增版本、修订保留历史、过期运行拒绝写入 |
| 引用 | 精确摘录、来源归属、字符位置、哈希、杜撰引文拒绝 |
| 记忆 | 提议不生效、用户确认、项目隔离、修改重新待确认、删除停止使用 |
| 来源 | 限定类型与大小、禁止目录穿越、隐藏路径与符号链接逃逸 |
| 工具循环 | 真实 SDK 的模型—工具—结果往返，模型/工具限额，越界工具拒绝 |
| 协议 | 真实 ChatAnthropic 客户端对合成 HTTP 的独立 key/endpoint/工具结果编码 |
| 发布安全 | credential repr 隐藏、回调尽力脱敏、Git 忽略规则 |
| CLI | 建任务、导资料、改约束、报告、记忆操作、结构化 trace、缺 key 报错 |

测试中的模型响应和 HTTP 响应均为预设数据，网络被阻断。不会因测试次数产生模型或搜索费用。
