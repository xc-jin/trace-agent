# 候选软件资料模板（逐项查证后再导入）

本文件是模板，不是产品介绍。不要把“待填写”或示例文字当作事实来源。

## 来源信息

- 产品名、版本或 commit：待填写。
- 资料标题与原始公开地址：待填写，不填写带认证参数、私有地址或临时凭据的链接。
- 采集日期：YYYY-MM-DD。
- 来源类型与局限：官方文档、仓库文件或其他公开材料；待说明。

## 可逐字引用的事实

- 部署方式：粘贴原文，不把“支持自托管”扩展为“也支持托管”。
- 文档类型与检索能力：粘贴原文；宣称存在能力与独立验证效果分开。
- 许可证名称及对应原始文件：粘贴相关事实；不要自行补写法律结论。
- 费用、硬件或运维信息：有资料就注明适用版本和条件，没资料就明确未知。

## 未查明事项

- 尚未找到或无法确认的信息：待填写。
- 没有进行的部署、质量或安全验证：待填写。

避免复制密钥、业务文档、客户信息、未经允许的内部资料或包含私有目录的终端输出。
