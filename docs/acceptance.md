## 覆盖的基本行为

| 范围 | 检查 |
| --- | --- |
| 任务与修订 | 定向失效、新约束保守复核、相同值不增版本、修订保留历史、过期运行拒绝写入 |
| 引用 | 精确摘录、来源归属、字符位置、哈希、杜撰引文拒绝 |
| 记忆 | 提议不生效、用户确认、项目隔离、修改重新待确认、删除停止使用 |
| 来源 | 限定类型与大小、禁止目录穿越、隐藏路径与符号链接逃逸 |
| 工具循环 | 真实 SDK 的模型—工具—结果往返，模型/工具限额，越界工具拒绝 |
| 依赖参数 | 动态枚举当前约束键、显式依赖、空依赖需说明、误填结论 ID 可纠正 |
| 复核范围 | 本轮保护未受影响结论，更新完待复核条目后保护仍有效；新运行不沿用旧批次 |
| 错误恢复 | 错误引用/来源/结论 ID 的结构化反馈、同一工具循环纠正、版本与资源错误仍硬停止 |
| 澄清状态 | 首步强制评估、存问题后无额外模型调用、等待重跑零请求、用户改约束解除等待、禁止绕过评估 |
| 协议 | 真实 ChatAnthropic 客户端对合成 HTTP 的独立 key/endpoint/工具结果编码 |
| 发布安全 | credential repr 隐藏、回调尽力脱敏、Git 忽略规则 |
| CLI | 建任务、导资料、改约束、报告、记忆操作、结构化 trace、缺 key 报错 |
| 场景模板 | 默认无虚构来源、显式导入示例、用户覆盖约束、重复演示项目隔离、离线不读凭据 |
| 变更交付 | 前后文本、默认/指定契约基线、同文新 revision、保留旧版本、来源定位、未知项、空记录/未评估/等待状态、只读导出 |

本次场景补全未新增付费 API 请求，下方真实调用记录属于此前修复版本，不是对新场景的真实模型质量验收。公开使用步骤见 `docs/knowledge-base.md`。

## 真实 API 回归（2026-10-16）

使用用户本机凭据调用 DeepSeek `deepseek-flash`，未调用 Tavily；仅使用仓库已有的虚构 Alpha/Beta 资料。每段仍限制为 8 次模型调用、18 次工具调用、120 秒协作式预算，没有为通过验收提高默认限额。

| 流程 | 模型请求 | 机械检查 |
| --- | --- | --- |
| 初始决策 | 6 | 部署、许可证适配结论分别声明对应约束依赖 |
| 修改部署约束后复核 | 6 | 受影响结论沿用原 ID、保留历史；许可证适配结论文本和 revision 不变；无剩余 needs_review |
| 缺少公司安全制度 | 1 | 先保存问题、无结论写入；程序立即结束并返回 needs_clarification |

以上成功回归共 13 次请求；SDK 记录输入 58,602、输出 3,220 tokens，不等于结算账单。此前同一次修改过程的一轮回归消耗 16 次请求，初始流程完成，但修订流程达到预算上限而失败；随后移除待办工具、增加本轮复核范围保护，再完成上表回归。失败记录未删除，不能据此宣称成本或成功率提升。

**机械检查通过不代表建议正确。** 人工阅读发现，初始回复推断“Beta 可托管亦可自托管”，但资料只说明其支持内网自托管，不能支持额外的托管能力。模型仍登记了重复的原始事实，空依赖事实在改约束后按既定规则保守复核。当前校验保证引用可定位、依赖键合法和流程边界，不保证语义蕴含、依赖完整或最少调用次数。

真实配置未复制到仓库，原始 trace、数据库、报告保留在 Git 忽略目录；扫描未发现原始 key 字节。原始运行数据不纳入版本控制，只发布代码、公开示例、测试与文档。
